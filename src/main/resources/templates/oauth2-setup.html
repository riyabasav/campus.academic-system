Google OAuth2 Credentials Setup Required

Why am I seeing this page?
Google OAuth2 requires a valid Client ID and Client Secret registered in the Google Cloud Console for http://localhost:8080.
How to Get Your Free Credentials (3 Steps):
  1. Go to Google Cloud Console Credentials .
  2. Click + CREATE CREDENTIALS → OAuth client ID → Select Web application.
  3. Add this exact URL under Authorized redirect URIs:
    http://localhost:8080/login/oauth2/code/google
